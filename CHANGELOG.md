# Changelog

## 1.7.0

- Added a dedicated modern weapon combat layer.
- Added Mace profiles and `/spawnbot mace`.
- Added Mace smash fall-distance damage, Density, Breach, Wind Burst and Wind Charge launch behavior.
- Added Spear profiles and `/spawnbot spear`.
- Added Spear jab/charge behavior, minimum reach and 4.5 block maximum reach.
- Added material-specific Spear charge multipliers and attack timing.
- Added Spear Sharpness and Lunge support.
- Added runtime Spear material detection for Java 1.21.11+.
- Added modern weapon state to Citizens bot traits.
- Added GitHub Actions build/test artifacts.
- Added tag-triggered GitHub Release publishing.
- Updated author metadata to THEMPGUY.
- Updated project URL to https://github.com/THEMPGUYAlt.
