## How to Build

### Requirements
- **Java**: JDK 21+
- **Maven**: 3.8+

### Build Command
```bash
git clone https://github.com/bb99kra/PracticeBot-Source.git
cd PracticeBot-Source
mvn clean package
```

The output JAR file will be available in `target/PracticeBot-1.6.2.jar`.
